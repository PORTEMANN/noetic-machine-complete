## 1. Le diagnostic (trois mécanismes mesurés)

Le continu résiste parce qu'il fabrique de l'ordre pour rien :

1. **Ordre cinématique** : produit télescopique (T36 : la moyenne des
   rapports = ombre des extrémités), incréments entiers (T33 : la
   « gamme tempérée » des noyaux), ratio unique (T31 : Bode). La
   structure apparente est le défaut de fabrication, pas la signature.
2. **Entiers de coupure** : les comptes dépendent de la résolution et
   gonflent sous la cascade (T34-D1 : filaments ; ν = 0 : 14 → 29).
3. **Le continu réussit en empruntant** : son contenu le plus solide est
   discret-importé (N = 18 de l'icosaèdre, T32 ; module m + nφ en espace
   réciproque, T27/T28).

## 2. L'approche : cinq piliers

1. **Invariants d'abord, lois ensuite** — lire le continu par ce qui
   survit à la déformation (circulation, hélicité, persistance) :
   déclarer l'invariant, mesurer sa violation.
2. **La persistance comme discrétisation native** — les entiers robustes
   sont les paires naissance-mort, pas les comptes de seuil (T34-D1).
3. **Modéliser dans l'espace dual** — Fourier, Galois, réciproque : le
   continu devient souvent discret dans son espace conjugué (T21, T29).
4. **Le flux de coupure comme objet premier** — mesurer comment les
   invariants coulent avec l'échelle : le continu = suite de cartes
   discrètes épinglées (dictionnaire T18 généralisé).
5. **Check-list des confondants cinématiques, obligatoire en fiche** —
   extrémités, incréments, coupure, convergents : déclarés avant run,
   comme le nul honnête.

Garde-fou fondateur (T35) : tout modèle continu est un **modèle
effectif** — régime de validité déclaré, coupure datée, falsifieur
attaché.
