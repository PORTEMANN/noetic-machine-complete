## 2. Les leçons de l'ère énergie

Quatre règles de méthode gravées en quatre campagnes :

1. **La monnaie étrangère était le forçage, pas la physique** (T56→T57) :
   une relation peut être réfutée dans un protocole et tenir dans un
   autre — le dormeur n'est pas une fin, c'est une promesse conditionnelle.
2. **Le silence est un instrument, pas un état** (T57-D1) : il est
   relatif (effondrement 5–19×), daté (le burst [60, 72] est une ère à
   part), et mérité — la fenêtre silencieuse se trouve, ne se décrète pas.
3. **Les références qui rapetissent rayonnent ; les pentes belles
   peuvent être des artefacts** (T58-D1) : un anneau qui rapetisse n'est
   pas une référence statique (la pente E vs Λ mêle tension et
   radiation : 28.9 au lieu de 15.7) ; et le R² ne valide pas l'objet
   (la pente d'artefact de n = 8, R² 0.95, μ = 1.14).
4. **Un CV relatif petit sur un offset grand cache une dérive absolue**
   (T59-D1) : CV 2.4 % de R ≈ −9300, c'est ~200 unités de dérive —
   assez pour manger 15 % d'un bilan serré.
