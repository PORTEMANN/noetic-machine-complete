## 3. Ce que l'ensemble sait faire — et ce qu'il refuse

**Il sait** : mesurer sans théorie mais avec mécanique ; dire non
(T56, Bode, S8, P2a) ; dater les événements (reconnexions, morts
d'entiers) ; tenir une veille pré-publiée (59 meV, JUNO, LEGEND) ;
consolider ses arcs ; parler plusieurs langages de signature (φ,
entiers topologiques, S+/P/S−, CS+).

**Il refuse** : tout paramètre ajusté ; toute prédiction d'expérience ;
le mot « vrai » pour le réel (règle T25 : « S+ compatible, avec
réserve » au mieux) ; les classes hors de portée (la bio « ~1 » déclarée
non mesurée plutôt que forcée).
